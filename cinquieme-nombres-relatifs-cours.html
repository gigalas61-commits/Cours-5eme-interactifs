Nombres relatifs

1. Découverte des nombres relatifs

Jusqu'à présent, tu as toujours travaillé avec des nombres positifs (ou nuls). Mais dans la vie courante, on rencontre souvent des situations où il faut aller « en dessous de zéro ».

Trois situations concrètes :
  • 🌡️ Une température de −5°C (il fait 5 degrés en dessous de zéro).
  • ⛰️ Une altitude de −120 m (120 mètres sous le niveau de la mer).
  • 🏢 Le parking d'un immeuble, situé au 2ᵉ étage sous-sol, noté −2.

2. La droite graduée

On peut représenter les nombres relatifs sur une droite graduée : on choisit une origine (le point qui correspond à 0), une unité de longueur, et un sens (généralement vers la droite pour les nombres positifs).

Abscisse : le nombre associé à un point sur une droite graduée s'appelle l'abscisse de ce point.

Exemple : si le point A est associé au nombre −3, on note A(−3) et on dit que « l'abscisse de A est −3 ».

Place les points sur la droite

Clique (ou touche) sur la droite graduée pour placer un point à l'abscisse indiquée.

Nombres opposés : deux nombres relatifs sont opposés lorsqu'ils ont la même partie numérique mais des signes contraires. Exemple : +6 et −6 sont opposés. Sur une droite graduée, deux points d'abscisses opposées sont symétriques par rapport à 0.

3. Comparer les nombres relatifs

Les règles

  • Un nombre positif est toujours plus grand qu'un nombre négatif.
    Exemple : +2 > −5
  • Entre deux nombres positifs, le plus grand est celui qui a la plus grande partie numérique.
    Exemple : +7 > +3
  • Entre deux nombres négatifs, le plus grand est celui qui a la plus petite partie numérique (celui qui est le plus proche de 0).
    Exemple : −2 > −8 (car −2 est plus proche de 0 que −8)
Sur la droite graduée : plus un nombre est à droite, plus il est grand.

4. Addition de nombres relatifs

Règle 1 — Même signe

On additionne les parties numériques et on garde le signe commun.

Exemple : (+3) + (+5) = +8   |   (−4) + (−2) = −6

Règle 2 — Signes contraires

On soustrait les parties numériques (la plus petite à la plus grande) et on garde le signe du nombre qui a la plus grande partie numérique.

Exemple : (+7) + (−2) = +5   |   (+3) + (−9) = −6

Visualiser sur la droite graduée

Additionner, c'est se déplacer sur la droite graduée : +n = avancer de n vers la droite, −n = reculer de n vers la gauche.

(−3) + (+6) = +3

5. Soustraction de nombres relatifs

Règle d'or : soustraire un nombre revient à ajouter son opposé.
a − b = a + (−b)

Exemple : (+5) − (+8) = (+5) + (−8) = −3

Exemple : (−2) − (−6) = (−2) + (+6) = +4

Exemple : (−4) − (+3) = (−4) + (−3) = −7

Exercice 3 — Comparer

Compare en utilisant < ou > : a) −7 … 3   b) −2 … −9   c) 0 … −1   d) −15 … −4

Voir la correction

a) −7 < 3 (négatif < positif)
b) −2 > −9 (−2 est plus proche de 0)
c) 0 > −1
d) −15 < −4 (−15 est plus loin de 0)

Exercice 4 — Additions

Calcule : a) (+8) + (+5)   b) (−6) + (−9)   c) (+7) + (−3)   d) (−10) + (+4)   e) (−2) + (+2)

Voir la correction

a) +13 (même signe : on additionne, on garde +)
b) −15 (même signe : on additionne, on garde −)
c) +4 (signes contraires : 7−3=4, on garde le signe du plus grand, +7)
d) −6 (signes contraires : 10−4=6, on garde le signe du plus grand en valeur, −10)
e) 0 (deux nombres opposés s'annulent)

Exercice 5 — Soustractions

Transforme en addition puis calcule : a) (+4) − (+9)   b) (−3) − (−8)   c) (−5) − (+2)   d) (+6) − (−1)

Voir la correction

a) (+4) − (+9) = (+4) + (−9) = −5
b) (−3) − (−8) = (−3) + (+8) = +5
c) (−5) − (+2) = (−5) + (−2) = −7
d) (+6) − (−1) = (+6) + (+1) = +7

Exercice 6 — Situation : le bilan d'un compte bancaire

Le compte de Léa affiche +45 €. Elle dépense 60 € puis reçoit 25 €. Quel est le nouveau solde ? Écris le calcul avec des nombres relatifs.

Voir la correction

Solde = (+45) + (−60) + (+25)
= (−15) + (+25)
= +10
Le compte de Léa affiche +10 €.

Exercice 7 — Températures et amplitude

À 6h du matin, il faisait −8°C. À 14h, il faisait +5°C. Quelle est l'augmentation de température (l'écart) entre ces deux relevés ?

Voir la correction

Écart = (+5) − (−8) = (+5) + (+8) = +13
La température a augmenté de 13°C.

Exercice 8 — Chaîne de calculs

Calcule astucieusement en regroupant : A = (−12) + (+8) + (−3) + (+12) + (−8)

Voir la correction

On regroupe les nombres opposés : (−12)+(+12) = 0, puis (+8)+(−8) = 0.
Il reste A = 0 + 0 + (−3) = −3
